# codyssey1-3

프로젝트 1 (비교): 같은 일(예: 설문 응답 저장)을 Make와 Zapier 두 가지 툴로 각각 만들어보고, 어떤 툴이 더 편한지, 비용은 어떤지 비교 분석하기.
프로젝트 2 (창작): 내가 평소에 귀찮아하던 업무를 하나 정해서, 나만의 자동화 파이프라인 만들기.
필수 조건:
Trigger(시작점) 1개
Action(동작) 2개 이상
Filter/Router(조건문: "만약 ~라면") 1개 이상 포함

1단계: 도구 준비하기
가장 대중적이고 무료 플랜이 잘 되어 있는 두 도구를 사용했습니다.

Make (구 Integromat): 시각적으로 연결하는 방식. 복잡한 로직 구현에 강하며 무료 실행 횟수(1,000번)가 넉넉했습니다.

Zapier: 가장 유명하고 직관적입니다. 초보자가 쓰기 매우 쉽지만, 무료 플랜의 제약이 조금 있었습니다.


2단계: [프로젝트 1] 비교 구현하기 (추천 시나리오)
주제: "구글 폼으로 강의 신청 시, 오전과 오후에 오는 수강신청자에게 별도의 안내 이메일 답신을 준다 "

설계:
Trigger: 구글 폼에 새 응답이 들어오면
Filter: 응답 내용 중 '오전/ 오후'이라는 단어가 포함되어 있는가?
Action 1: 구글 스프레드시트에 행 추가
Action 2: 슬랙(Slack) 또는 이메일로 알림 발송
수행: 이 흐름을 Make에서 한 번, Zapier에서 한 번 똑같이 만들었습니다.

비교: 
Make은 필터 설정이 눈에 보여서 편했습니다.
Make 처리 속도가 빨랐고 가격도 저렴했습니다.
Zapier는 적은 클릭으로 쉽게 연결 됐습니다.
Zapier 처리 속도가 느렸습니다.
유료버전이 바로 필요했습니다.


3단계: [프로젝트 2] 구글폼에 오전과 오후 신청자를 나눠서 각각에 맞는 안내 이메일을 자동으로 보낸다.

일정 관리: 구글 폼에 새로운 신청자가 들어오면 15분마다 확인 후  → 구글시트에 각각의 탭에 정리흘 한다. → 각각의 신청자 탭에 있는 이메일로 안내 답장 이메일 전송
