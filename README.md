# codyssey1-3

프로젝트 1 (비교): 같은 일(예: 설문 응답 저장)을 Make와 Zapier 두 가지 툴로 각각 만들어보고, 어떤 툴이 더 편한지, 비용은 어떤지 비교 분석하기.
프로젝트 2 (창작): 내가 평소에 귀찮아하던 업무를 하나 정해서, 나만의 자동화 파이프라인 만들기.
필수 조건:
Trigger(시작점) 1개
Action(동작) 2개 이상
Filter/Router(조건문: "만약 ~라면") 1개 이상 포함

2. 단계별 수행 방법 가이드 🚀
1단계: 도구 준비하기
가장 대중적이고 무료 플랜이 잘 되어 있는 두 도구를 추천합니다.

Make (구 Integromat): 시각적으로 연결하는 방식. 복잡한 로직 구현에 강하며 무료 실행 횟수(1,000번)가 넉넉합니다.
Zapier: 가장 유명하고 직관적입니다. 초보자가 쓰기 매우 쉽지만, 무료 플랜의 제약이 조금 있습니다.
2단계: [프로젝트 1] 비교 구현하기 (추천 시나리오)
주제: "구글 폼 설문 응답 시, 특정 키워드가 있으면 시트에 저장하고 슬랙 알림 보내기"

설계:
Trigger: 구글 폼에 새 응답이 들어오면
Filter: 응답 내용 중 '긴급'이라는 단어가 포함되어 있는가?
Action 1: 구글 스프레드시트에 행 추가
Action 2: 슬랙(Slack) 또는 이메일로 알림 발송
수행: 이 흐름을 Make에서 한 번, Zapier에서 한 번 똑같이 만듭니다.
비교: "Make은 필터 설정이 눈에 보여서 편하네?", "Zapier는 클릭 몇 번으로 연결되네?" 등의 경험을 기록하세요.
3단계: [프로젝트 2] 자유 주제 구현하기 (아이디어 예시)
자신이 겪는 불편함을 해결해 보세요.

뉴스 모니터링: 특정 키워드의 뉴스(RSS)가 뜨면 → **AI(ChatGPT)**로 요약해서 → 나에게 텔레그램으로 전송.
일정 관리: 구글 캘린더에 새 일정이 생기면 → 내일 날씨를 확인해서 → 비 소식이 있으면 "우산 챙기세요" 알림 보내기.
이메일 정리: 특정 보낸이의 메일이 오면 → 첨부파일을 구글 드라이브에 저장 → 팀 채널에 공유.
4단계: 보고서 작성 (Markdown 활용)
결과물은 깔끔한 문서로 정리해야 합니다.

스크린샷 필수: 워크플로우 전체 화면, 실행 성공 로그(History) 화면을 꼭 찍으세요.
조건 분기 증명: "조건이 맞을 때"와 "맞지 않을 때" 결과가 어떻게 다른지 보여주면 완벽합니다.
